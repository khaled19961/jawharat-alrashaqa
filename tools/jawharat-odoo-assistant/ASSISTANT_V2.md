# مساعد جوهرة الرشاقة V2

هذا الإصدار موجود على الفرع `jawharat-assistant-v2` ولا يغيّر قاعدة Odoo أو نسخة التشغيل الحالية حتى يتم مراجعته ونشره.

## الوظائف
- محادثة عربية مع بث الردود عبر Workers AI.
- نسخ رد المساعد بالنص الأصلي دون حذف علامات الترقيم.
- إرفاق صور PNG/JPG/WEBP وتحليلها عبر نموذج رؤية عند توفره.
- إرفاق PDF واستخراج نص أول 40 صفحة من المتصفح؛ الصفحات الممسوحة ضوئيًا تحتاج OCR منفصلًا.
- فحص اتصال MCP واستدعاء أدوات القراءة الفعلية.
- لوحة تعرض عدد أدوات القراءة والإنشاء والتحديث كما يعلنها خادم MCP.
- طلب موافقة من واجهة المستخدم قبل أي أداة تعديل.
- حماية من جهة الخادم تسمح بالإنشاء والتحديث فقط على `website.page` و`website.menu` و`website` و`ir.ui.view` و`website.snippet.filter`، مع موافقة واجهة لكل عملية.
- منع الحذف والتغييرات في المحاسبة والضرائب والزكاة والفواتير والقيود والمخزون والطلبات والأسعار وطرق الدفع والمستخدمين والصلاحيات.
- لا تعرض أسرار الاتصال داخل الواجهة.

## متطلبات التشغيل
إعدادات Worker المطلوبة كما هي في الإصدار الحالي:
- `ODOO_MCP_URL`
- `ODOO_MCP_TOKEN` كـ Secret
- `APP_PASSWORD` كـ Secret
- `SESSION_SECRET` كـ Secret
- ربط Workers AI باسم `AI`

لا يُفترض أن رابط `/mcp` يعمل لمجرد وجوده؛ يجب التحقق من عنوان MCP الفعلي وترويسة المصادقة. لا تضع الأسرار في GitHub أو المحادثة.

## التحقق قبل النشر
1. شغّل `npm ci`
2. شغّل `npm run check`
3. شغّل `npm run build`
4. اختبر تسجيل الدخول واتصال MCP.
5. اختبر القراءة على بيانات وصفية غير حساسة.
6. اختبر أن الكتابة على نموذج خارج قائمة السماح تُرفض من الخادم حتى لو طلبها النموذج.
7. اختبر أن الحذف مرفوض دائمًا.
8. لا تنشر إلى الإنتاج قبل مراجعة النتائج.

## حدود الإصدار
لو لم يعلن MCP أدوات إنشاء أو تحديث فعلية، ستظهر الأعداد صفرًا ولن يخترع المساعد قدرة غير متاحة. لا تعني الموافقة أن الأداة نجحت؛ يجب التحقق من نتيجة MCP وقراءة السجل مجددًا عند توفر أداة قراءة مناسبة.


## ملاحظات التحقق للمرفقات والبحث
- الحد الأقصى للملف الواحد 12MB، وبحد أقصى 8 ملفات لكل إرسال.
- يجب اختبار توفر نموذج `@cf/meta/llama-4-scout-17b-16e-instruct` في حساب Cloudflare قبل الاعتماد على تحليل الصور.
- تحليل PDF الحالي يعتمد على النص القابل للاستخراج، ولا ينفذ OCR للصفحات المصورة.
- البحث في الإنترنت وYouTube ومصادر Odoo يعتمد على أدوات فعلية متاحة في اتصال MCP؛ لا يوجد زحف تلقائي أو تدريب ذاتي لأوزان النموذج في هذا الإصدار.
- تعديلات `ir.ui.view` قد تؤثر في قوالب الموقع، لذلك راجع تفاصيل كل عملية قبل الموافقة واختبرها في بيئة تجريبية.
