# جوهرة الرشاقة — نقل واجهة D-Nutrition-Care إلى Odoo 20

هذا المستودع نسخة تطوير مستقلة لنقل واجهة الموقع الحالية إلى وحدة Odoo. لا يستبدل هذا المستودع مستودع `D-Nutrition-Care` ولا يعدّل موقع Cloudflare المنشور.

## مبدأ العمل

- الحفاظ على التصميم العربي RTL والأقسام والهوية المرئية قدر الإمكان.
- تحويل الكتالوج والسلة والطلبات إلى وظائف Odoo القياسية بدلًا من الاعتماد على Next.js/Supabase.
- لا تُستخدم قاعدة بيانات إنتاج ولا تُنفّذ عمليات نشر من هذا المستودع دون موافقة صريحة.
- أي صور تُستخدم من الموقع الحالي في مرحلة المعاينة تظل اعتمادًا مؤقتًا؛ يجب نقلها إلى أصول الوحدة قبل الإطلاق.

## الحالة

بدأت المراجعة المعمارية. ستوضع وحدة Odoo في `addons/jawharat_storefront/` على فرع تطوير منفصل. هذه النسخة الأولية لا تعني أن الوحدة اختُبرت على خادم Odoo 20؛ يجب اختبارها على بيئة تطوير قبل التثبيت أو النشر.

## متطلبات المرحلة الأولى

- Odoo 20 مع `website` و`website_sale`.
- بيئة اختبار منفصلة.
- مراجعة واجهة الموقع الحالية قبل اعتماد التحويل النهائي.

## أمان

لا تضف مفاتيح API أو كلمات مرور أو ملفات `.env` أو بيانات العملاء إلى GitHub. لا تربط هذه الوحدة بقاعدة بيانات إنتاج أثناء التطوير.
