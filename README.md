# جوهرة الرشاقة — نقل واجهة D-Nutrition-Care إلى Odoo 20

هذا المستودع نسخة تطوير مستقلة لنقل واجهة الموقع الحالية إلى وحدة Odoo. لا يستبدل هذا المستودع مستودع `D-Nutrition-Care` ولا يعدّل موقع Cloudflare المنشور.

## ما أُنشئ

- وحدة Odoo أولية في `addons/jawharat_storefront/` على فرع `odoo-port`.
- رأس وتذييل عربيان RTL وقالب صفحة رئيسية يستخدم منتجات وتصنيفات Odoo المنشورة.
- نموذج لإدارة البنرات الثابتة والمتحركة من واجهة Odoo.
- نسخة من CSS الأصلي مع طبقة تكييف صغيرة لقوالب Odoo.

## قبل التثبيت

- يتطلب هذا الإصدار الأولي Odoo 20 مع تطبيقي `website` و`website_sale`.
- لم يتم اختبار الوحدة على خادم Odoo فعلي؛ لا تثبّتها على قاعدة إنتاج قبل اختبار XML/QWeb على بيئة تطوير.
- البنرات الثابتة وبقية صور البنرات التي كانت تُقرأ من Supabase لم تُصدّر بعد. توجد ثلاثة ملفات بنرات محلية فقط في المستودع المصدر، وتستخدم النسخة الحالية روابط مؤقتة لها كخيار احتياطي.
- لم يتم نقل المنتجات أو العملاء أو الطلبات أو إعدادات الدفع والشحن.
- لا توجد أي عملية نشر أو تعديل لقاعدة بيانات في هذه المرحلة.

## خطوات التطوير الآمنة التالية

1. نقل صور البنرات المتبقية إلى سجلات `jawharat.banner` داخل بيئة Odoo تجريبية.
2. تثبيت الوحدة على قاعدة اختبار فقط والتحقق من معرّفات القوالب والحقول في إصدار Odoo المستهدف.
3. مقارنة الصفحة بصريًا مع الموقع الحالي على الجوال والكمبيوتر.
4. ربط الطلبات والمخزون والمحاسبة باستخدام وظائف Odoo القياسية.
5. مراجعة الاختبارات والأمان قبل أي نشر، بموافقة صريحة.

## أمان

لا تضف مفاتيح API أو كلمات مرور أو ملفات `.env` أو بيانات العملاء إلى GitHub. لا تربط هذه الوحدة بقاعدة بيانات إنتاج أثناء التطوير.
