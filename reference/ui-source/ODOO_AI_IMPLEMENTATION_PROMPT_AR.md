الهدف هو إعادة بناء الواجهة المرجعية بأعلى تطابق بصري ممكن داخل موقع Odoo Online الحالي، لكن اسم العلامة التجارية الفعلي للموقع يجب أن يكون «جوهرة الرشاقة» (Jawharat Al-Rashaqa عند الحاجة إلى الاسم الإنجليزي).

مهم جدًا بشأن الاسم والهوية:
- D-Nutrition-Care اسم المشروع المرجعي الذي أُخذت منه ملفات التصميم فقط، وليس اسم المتجر الجديد.
- لا تُظهر عبارة D-Nutrition-Care في أي مكان ظاهر للزائر: الشعار، اسم الموقع، الهيدر، شريط الإعلان، القوائم، التذييل، عنوان المتصفح، SEO/meta title أو description، Open Graph، النصوص البديلة أو أي قسم آخر.
- استبدل الهوية الظاهرة بالكامل بهوية «جوهرة الرشاقة»، مع الاحتفاظ بتخطيط وتصميم المرجع وألوانه وأبعاده قدر الإمكان.
- افحص الصور والبنرات نفسها؛ إذا احتوت على اسم أو شعار D-Nutrition-Care، فلا تعرضها كما هي. استخدم نسخة مسموحًا بها تجاريًا بهوية «جوهرة الرشاقة» مع المحافظة على قياسات وتوزيع البنرات، ولا تغيّر عناصر التصميم الأخرى بلا داعٍ.
- لا تغيّر اسم مستودع المصدر أو ملفاته الأصلية؛ استخدمها مرجعًا فقط.

ابدأ بقراءة الملفات الخمسة كاملة: app/page.tsx و components/home-storefront.tsx و components/site-chrome.tsx و components/navigation.tsx و app/globals.css. جهّز خريطة مطابقة لكل قسم ومقاس ولون ومسافة وسلوك استجابة. استخدم ملفات TSX كمصدر ترتيب المحتوى والمكونات، وglobals.css كمصدر الحقيقة للتصميم والتجاوب.

لا تحاول تشغيل Next.js أو React داخل Odoo Online، ولا تكتفِ بوصف نصي أو بتعديل البنرات فقط. حوّل الواجهة إلى عناصر Odoo Website المدعومة فعليًا، مع CSS/JS متوافق مع Odoo Online، واحتفظ ببيانات المنتجات والتصنيفات وروابط التجارة من سجلات Odoo الحقيقية.

لا تغيّر المحاسبة أو المخزون أو المنتجات أو أي إعداد غير متعلق بتصميم الموقع. لا تعلن أن التصميم مطابق قبل مقارنة لقطات شاشة حقيقية على الكمبيوتر والتابلت والجوال، والتحقق من أن اسم «جوهرة الرشاقة» وحده هو الظاهر للعميل، وفحص اختلافات الأقسام والهوامش والأحجام والألوان واتجاه RTL وسلوك القائمة والسلايدر. إذا تعذّر عليك قراءة ملفات GitHub أو الوصول إلى أداة تعديل واجهة Odoo، اذكر القيد بدل الادعاء بالإنجاز.
