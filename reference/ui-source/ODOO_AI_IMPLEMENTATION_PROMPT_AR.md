المطلوب ليس تصميم متجر مشابه. المطلوب إعادة بناء واجهة D-Nutrition-Care المرجعية بأعلى تطابق بصري ممكن داخل موقع Odoo Online الحالي.

ابدأ بقراءة الملفات الخمسة كاملة: app/page.tsx و components/home-storefront.tsx و components/site-chrome.tsx و components/navigation.tsx و app/globals.css، ثم جهّز خريطة مطابقة لكل قسم ومقاس ولون ومسافة وسلوك استجابة. استخدم ملفات TSX كمصدر ترتيب المحتوى والمكونات، وglobals.css كمصدر الحقيقة للتصميم والتجاوب.

مهم: لا تحاول تشغيل Next.js أو React داخل Odoo Online، ولا تكتفِ بوصف نصي أو بتعديل البنرات فقط. حوّل الواجهة إلى عناصر Odoo Website المدعومة فعليًا، مع CSS/JS متوافق مع Odoo Online، واحتفظ ببيانات المنتجات والتصنيفات وروابط التجارة من سجلات Odoo الحقيقية.

لا تغيّر مستودع D-Nutrition-Care الأصلي. لا تغيّر المحاسبة أو المخزون أو المنتجات أو أي إعداد غير متعلق بتصميم الموقع. لا تعلن أن التصميم مطابق قبل مقارنة لقطات شاشة حقيقية على الكمبيوتر والتابلت والجوال مع المرجع، وفحص اختلافات الأقسام، والهوامش، والأحجام، والألوان، واتجاه RTL وسلوك القائمة والسلايدر. إذا تعذّر عليك قراءة ملفات GitHub أو الوصول إلى أداة تعديل واجهة Odoo، اذكر القيد بدل الادعاء بالإنجاز.
